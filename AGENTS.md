# Project instructions

- Use Rust for application and database tooling. Do not add Python or shell-script implementations.
- Keep every data build idempotent and reproducible from declared inputs.
- Never treat a fuzzy title match as an accepted identity link.
- Do not commit provider data unless its redistribution terms have been recorded and permit it.
- Run formatting, tests, a strict database audit, and archive verification before committing.
- After completing a requested change, commit the relevant files and push the current branch.
