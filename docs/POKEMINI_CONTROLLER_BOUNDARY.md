# PokeMini controller boundary

Official SourceForge v0.60 artifacts are pinned by SHA-256 in the record. The artifact README documents fixed PC keyboard defaults and launch-only `-joystick`/`-joyid` options, plus `-eeprom` and `-state` paths. No persistent controller mapping file or grammar is documented, so the adapter refuses controller serialization. Linux and Windows artifact behavior is not runtime-verified; macOS and Flatpak are unsupported by the release set.
