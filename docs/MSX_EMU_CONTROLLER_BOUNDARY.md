# MSX.emu controller boundary

The official ExPlusAlpha page (<https://www.explusalpha.com/contents/msx-emu/>)
identifies MSX.emu as a proprietary Android/iOS/Linux-family emulator and
advertises external controller support, but publishes no inspectable native
configuration grammar, device identity, save-state naming, or firmware
contract. The adapter refuses to invent a host profile or infer private mobile
storage paths. Runtime and platform parity remain unverified.
