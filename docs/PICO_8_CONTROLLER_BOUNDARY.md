# PICO-8 controller boundary

The official proprietary manual documents config locations for Windows, macOS, and Linux (`config.txt`, lines 247-259), SDL2 controller mappings in `sdl_controllers.txt` (lines 296-311), and `KEYCONFIG` (lines 58-67). It does not publish a complete stable grammar for safely patching those files. The adapter records these source-backed paths but refuses to synthesize controller config text. PICO-8 is a product, not an open-source repository; exact version, license, package, and runtime behavior remain unverified.
