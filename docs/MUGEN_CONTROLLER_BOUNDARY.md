# MUGEN controller boundary

The exact Elecbyte MUGEN record is fail-closed. The official MUGEN 1.1 documentation at <https://www.elecbyte.com/mugendocs-11b1/mugen.html> is a documentation page, not a current source repository or pinned distribution. Its game-specific `system.def` and input sections do not establish a stable host controller-profile file or device-identity selector.

No desktop writer is implemented. Ikemen GO is a separate engine and is not substituted for MUGEN. Runtime, binary version, save/state paths, and controller persistence remain unverified.
