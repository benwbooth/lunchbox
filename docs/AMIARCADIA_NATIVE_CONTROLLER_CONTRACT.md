# AmiArcadia native controller contract

This contract is source-backed against `warmenhoven/amiarcadia@8ca27c925833fe0021475155512c7f467924f647`.

WinArcadia stores its configuration as line-oriented `key=value` text in
`Configs\\WinArcadia.ini`, relative to its working directory. The source
serializes `controller_left` and `controller_right` with values 0 through 8,
and `leftbutton_0..7` / `rightbutton_0..7` with one-based selectors into the
eight-entry `joyfires[]` table. DirectInput reads the first two attached
joysticks at runtime, using fixed X/Y axes and `rgbButtons`; product names are
displayed at runtime but are not persisted as device identities.

WinArcadia's reader consumes the serialized schema in a fixed order rather
than searching freely for labels. `controller_amiarcadia_native.rs` therefore
patches those eighteen source-defined fields only in place in a complete INI
generated by the same executable, retaining ordering, line endings and all
other serialized settings. It rejects incomplete baselines, out-of-range
button selectors, and duplicate fields instead of appending plausible but
ineffective keys. The launch layer must resolve and recheck the DirectInput
devices before starting WinArcadia. The writer does not claim libretro
frontend mapping, save-data portability, or platform parity.
