# Azimuth artifact boundary

The only official artifact located for `johnidis.azimuth` is its Google Play
listing, updated 2025-12-21: <https://play.google.com/store/apps/details?id=johnidis.azimuth>.
The listing describes an Android Amstrad CPC emulator with on-screen and
external controller support, disk/tape operations, and in-app content, but it
does not publish an APK digest, source repository, host config path, input-map
serialization, save-state naming, or firmware/key contract.

Accordingly the catalog record marks all desktop host platforms unsupported and
adds no native writer. Inferring Android private-storage paths or reverse
engineering an unpinned APK would not be source/artifact-backed adapter work.
