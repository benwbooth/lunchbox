# Provenance controller boundary

The Provenance project is pinned to
`Provenance-Emu/Provenance@93f49b4079df204fcd77f29883d00bb5bde629d4`.
Its official site describes an open-source emulator for iPhone, iPad, and
Apple TV. No Linux, Flatpak, Windows, or macOS desktop package or persistent
desktop controller grammar is established by this catalog entry. Lunchbox
fails closed and does not invent one; Apple runtime input and persistence need
their own platform-specific inspection.
