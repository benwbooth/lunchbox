Lunchpail

Your retro game collection, ready to play.

A free, open-source game library and emulator frontend for Windows, macOS, and Linux.

Linux · Flatpak

Install Lunchpail

Open this file in Discover or another Flatpak-compatible software manager. It adds the signed Lunchpail update source and the required runtime source.

Or, with Flatpak installed, run:

flatpak install --user https://benwbooth.github.io/lunchpail/lunchpail.flatpakref
flatpak run @APP_ID@
@LEGACY_RELEASE_NOTE@

Updates appear in your software manager. From the terminal, use flatpak update --user.

For an existing Flatpak setup, you can also add the repository separately.

macOS · Homebrew

Apple Silicon, macOS 13 or later:

brew install --cask benwbooth/lunchpail/lunchpail

Update with brew update && brew upgrade --cask lunchpail.
